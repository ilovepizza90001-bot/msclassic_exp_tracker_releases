# MS Classic EXP Tracker — Downloads

Windows app downloads and signed update metadata live here. Source code is maintained separately.

## Install

Open [Releases](https://github.com/ilovepizza90001-bot/msclassic_exp_tracker_releases/releases/latest), download the Windows x64 ZIP, extract **all** files, and run `MSClassicExpTracker.exe`. Keep `_internal` beside the executable. Python is included.

Requires Windows 10/11 x64 and Windows English (United States) OCR. Keep the game foreground with its bottom HUD visible, then start tracking. Screens are checked every 10 seconds. Normal captures stay in memory.

The app checks for signed updates at startup and through its Updates button. You choose when to download and restart. No GitHub login is required.

The first release is being prepared; a download is available once a release appears above.
